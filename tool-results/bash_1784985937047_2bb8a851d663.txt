# Turbopay — Comprehensive Research Report

## 1. Project Overview

**Turbopay** is a **consumer-facing Nigerian fintech web application** — a digital wallet + payments platform explicitly modelled on OPay, PalmPay, Kuda, Wise, and Revolut. The README tagline is *"The fast lane to your money."*

- **Purpose:** Fund a wallet, transfer money (internal Turbopay ↔ Turbopay, and external to any Nigerian NUBAN bank account), buy airtime & data bundles, pay bills (electricity, cable TV, internet, water, Remita, Quickteller), request international transfers, hold multi-currency balances, issue virtual cards, run savings goals & investments, redeem vouchers, earn referrals/cashback rewards, raise and track disputes, and operate an admin compliance/risk console.
- **Target users:** Everyday Nigerian consumers (with multi-country expansion to Ghana, Kenya, South Africa, UK). Two personas are surfaced in code: regular **Users** (default role `USER`) and **Admins** (`ADMIN`).
- **Repository state:** Public GitHub repo `ifeanyiokomba/Turbopay`, TypeScript primary language, 0 stars at the time of research, last pushed 2026-07-25, current app version `0.3.0` per CHANGELOG. No license file committed at repo root (README claims MIT).
- **Architecture summary (per README):** the codebase is divided into a deprecated `src/` payment-orchestration SDK and the canonical Next.js app `turbopay-complete-latest/`. The Next.js app is the single source of truth. A small `frontend/` directory holds a separate (older, mock-data) Next.js 14 admin/customer/merchant dashboard that is **not** the production UI.

## 4. Page / Route Inventory

### 4.1 The SPA shell (`/`)
A single Next.js page at `src/app/page.tsx` bootstraps the entire app. It calls `/api/auth/me` on mount, then renders one of:
- **`<LoadingScreen />`** — premium animated splash (logo fade-rise + sheen sweep).
- **`<LandingPage />`** — guest landing (hero, features, how-it-works, security/trust, why Turbopay, FAQ, testimonials, CTA, footer). Logged-out users see this.
- **`<AuthScreen />`** — login/register modal (Tabs: Sign in / Create account, plus Forgot-password, MFA challenge, Email/SMS/WhatsApp verify dialogs, Google sign-in button).
- **`<AppShell />`** — the authed SPA. Renders the active view from `useApp.view`. Has a left desktop sidebar, sticky top header (theme toggle, notifications bell, avatar dropdown), bottom mobile nav (Home / Wallet / Send / Bills / History), 15-min inactivity auto-logout with 2-min warning dialog, notifications panel (top-right), `<AiSupport />` floating chat widget, global PIN dialog provider.

### 4.2 Non-authed public routes
- `/` — bootstrap SPA
- `/privacy` — privacy policy page
- `/terms` — terms of service page
- `/pay/[reference]` — public payment link landing (server component fetches `PaymentLink`, renders `<PaymentLinkClient />` for payment)
- `/admin/login`, `/admin/forgot-password` — admin login / forgot-password (separate auth from user auth)
- `/sentry-example-page` — Sentry test page

### 5.1 Brand / shell components (`src/components/turbopay/`)

- **`LoadingScreen`** — animated wordmark splash (fade-rise per letter + sheen sweep on loop).

Sections: sticky navbar, hero (badge, headline, subcopy, CTA buttons, trust badges, wallet-card mockup with floating stat cards), features grid (6 cards), how-it-works (3 steps), trust section (dynamic from DB), why Turbopay (4 cards), FAQ accordion, testimonials (from DB or placeholder), final CTA, footer (4-col + status indicator).
- **`AuthScreen`** — 1,050-line component. Two-column on desktop: left brand panel (logo, headline "The fast lane to your money", 3 feature bullets), right form panel (Tabs: Sign in / Create account). Login: identifier + password + forgot link. Register: first/middle/last name, country selector, optional username/email/phone, password with live strength checklist, referral code, terms checkbox. Includes ForgotPasswordDialog, MfaChallengeDialog, VerifyDialog (Email/SMS/WhatsApp channels), GoogleSignInButton.

Renders sidebar (desktop) / Sheet (mobile) / bottom nav (mobile), header (theme toggle, notifications bell, avatar dropdown), session timeout warning dialog (15-min auto-logout with 2-min countdown), notifications panel, view router (`renderView()` switch), `<AiSupport />` floating chat, `<PinDialogProvider />`, `<I18nProvider />`.
